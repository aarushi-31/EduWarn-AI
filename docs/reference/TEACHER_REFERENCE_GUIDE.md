# Teacher Reference Guide & Academic Formatting Standards
## Software Engineering Lab (JCSAIMLL-001)

### 1. Document Formatting Specifications
- **Paper Size**: A4, portrait (landscape allowed only for wide diagrams/tables)
- **Font**: Times New Roman (12pt main text, 14pt bold experiment headings, 16pt uppercase main headings, 12pt bold subheadings)
- **Line Spacing**: 1.5 for main text, paragraph spacing 0pt before / 6pt after
- **Margins**: 1 inch on all sides
- **Figures & Tables**: Sequentially numbered with meaningful captions (figures below, tables above)

### 2. Standard Structure Required for Each Experiment Report
Every experiment in the practical lab record must include:
1. **Experiment Number and Title**
2. **Aim**
3. **Theory**
4. **Requirements / Tools Used**
5. **Procedure**
6. **Diagrams / Relational Schemas / Source Code** (as applicable)
7. **Output / Execution Screenshots / Observations** (genuine outputs)
8. **Result**
9. **Viva Questions and Answers**

### 3. Key Academic Principles
- Use one consistent software project across all experiments.
- Do not submit purely theoretical descriptions for implementation experiments (Exp 6, 7, 8, 9, 10, 11, 12).
- Use genuine outputs and test runs; no fabricated results or mock screenshots.
- Implement proper traceability between SRS requirements, UML design, database tables, source code, test cases, and test reports.
